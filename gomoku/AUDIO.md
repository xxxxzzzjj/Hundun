# 五子棋音效清单（v2 · 实际生效版）

> 本文件已按**代码里真实引用的文件名**重写（旧版提到的 `playChessSound` 是不存在的函数名，实际函数叫 `gmkSnd`）。

## 一、放哪里

**全部放在 `Hundun/` 根目录**（和 `index.html` 同级），**不要**放进 `imgs/gomoku/`。

```
Hundun/
├── index.html
├── bgm.mp3                ← 已有：全局背景音乐（不是五子棋专用的）
├── button.mp3             ← 已有：全游戏通用按钮音（不是五子棋专用的）
├── chess_drop.mp3         ← 五子棋：落子
├── chess_card.mp3         ← 五子棋：用技能卡 / 刷新卡牌
├── chess_win.mp3          ← 五子棋：你赢了
├── chess_lose.mp3         ← 五子棋：你输了 / 认输
└── chess_undo.mp3         ← 五子棋：悔棋生效
```

## 二、有效文件名（一字不差，全小写 + 下划线）

| 文件名 | 什么时候响 |
|---|---|
| `chess_drop.mp3` | **落子**：你点棋盘下子的瞬间（不等服务器返回） |
| `chess_card.mp3` | **用技能卡成功**后；以及**刷新卡牌成功**后 |
| `chess_win.mp3` | 结算时**你赢了**（五连 / 对方认输 / 对方掉线 / 对方踩雷后你连五） |
| `chess_lose.mp3` | 结算时**你输了**；以及**你自己点认输**时 |
| `chess_undo.mp3` | 对方请求悔棋、**你点「同意」**时 |

> 格式：**mp3** 最保险（所有浏览器都支持）。文件名必须和上表完全一致。

## 三、音量与开关

游戏内 **设置** 面板里有两个滑条 + 两个勾选框：

| 设置项 | 管什么 | 存储键（localStorage） |
|---|---|---|
| ☑ 开启棋子 / 技能音效 | 上面这 5 个音效的总开关 | `gomoku_piece_on`（`'0'` = 关） |
| 棋子音效音量 | 5 个音效的音量（0~100） | `gomoku_piece_vol`（默认 60） |
| ☑ 开启下棋背景音乐 | **全局** `bgm.mp3` 的对局开关 | `gomoku_bgm_on`（`'0'` = 关） |
| 背景音乐音量 | 只在五子棋界面内生效 | `gomoku_bgm_vol`（默认 60） |

⚠️ **背景音乐的音量只在五子棋界面里临时改**，退出对局会自动恢复你原来在「设置中心」里的全局音乐音量 —— 不会污染其他功能。

## 四、缺文件会怎样

**不会报错，也不会卡住。** 代码用 `new Audio(...)` + `.catch()` 兜住了：文件不存在 → 播放失败 → 静默跳过。

所以你可以**只放其中几个**，甚至一个都不放（全程静音）。

> 唯一的表现：浏览器开发者工具的 Network 面板里会看到 `chess_xxx.mp3` 的 404。不影响功能。

## 五、自检

传完音效后，进对局依次试：

1. 落子 → 响 `chess_drop.mp3`
2. 用一张技能卡 → 响 `chess_card.mp3`
3. 点「刷新」→ 响 `chess_card.mp3`
4. 让对方点悔棋、你点同意 → 响 `chess_undo.mp3`
5. 打完一局 → 响 `chess_win.mp3` 或 `chess_lose.mp3`
6. 设置里把「棋子音效」取消勾选 → 上面全部静音

**现在这 5 个文件一个都没有**，所以你的对局目前是全程静音的。
